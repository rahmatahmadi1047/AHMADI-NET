# VPN Android app

Persian RTL Android UI using the official embeddable WireGuard tunnel library.

## Build
The GitHub Actions workflow builds a debug APK and uploads it as an artifact.

## Important
The app does not include a VPN server. To connect, each user needs a valid WireGuard client configuration issued by a reachable WireGuard server. Do not commit real private keys or production configuration files to this repository.
